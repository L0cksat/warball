## Overview

Project Warball is an automated, browser-based text sports simulation game[cite: 2]. Inspired by the blaseball.com style[cite: 2], this project translates a fictional sport played in the fantasy setting of Earisia[cite: 1] into a live, interactive web dashboard. The game requires no direct player input[cite: 2]; instead, an autonomous backend engine calculates passes, tackles, and shots using dynamic mathematical models, broadcasting the results in real-time to the client.

The foundational lore, game mechanics, and initial design specifications driving this engine are thoroughly documented in the `Warball.md` and `project_warball.md` reference files.

## System Architecture

This project employs a monorepo structure, dividing the application into two primary directories:

*   **Frontend (`/frontend`):** Built with Angular[cite: 2]. It consumes REST APIs to display team and player statistics and utilizes Server-Sent Events (SSE) to render the live, scrolling text feed of active matches.
*   **Backend (`/backend`):** Built with Java and Spring Boot[cite: 2]. It houses the core `SimulationEngineService`, a scheduled task runner that processes match ticks and calculates interactions between the 18-player rosters[cite: 1].

### Database Strategy

The application leverages a dual-database approach to optimize performance:
*   **MySQL:** Acts as the persistent, relational data store. It maintains the hierarchical structure of Teams, Roster assignments, and nested JSON attributes for individual players[cite: 2].
*   **MongoDB:** Serves as the high-speed document store for the live simulation. It temporarily caches match states and handles the rapid read/write cycles generated by the event logs[cite: 2].

## Version 1 Features

The current iteration of Project Warball includes the following core functionalities[cite: 2]:

*   **Live Match Feed:** Unidirectional streaming of ongoing games (`/match/{match_id}`).
*   **Team Directories:** Comprehensive views of all active teams (`/teams`) and specific team profiles (`/teams/{team_id}`).
*   **Roster Management:** Access to team-specific players within the team profile.
*   **Player Profiles:** Detailed attribute breakdowns for individual players (`/teams/{team_id}/{player_id}`).
*   **Historical Tracking:** Persistent tracking of team history (`/{team_id}/history`) and individual player career milestones (`/{player_id}/player_history`).

## Local Development Setup

### Prerequisites
*   Node.js & npm (for Angular)
*   Java 17+ & Maven (for Spring Boot)
*   MySQL Server (Port 3306)
*   MongoDB Server (Port 27017)

### Starting the Backend
1. Navigate to the `backend` directory.
2. Ensure MySQL and MongoDB instances are running locally.
3. Update `application.properties` with your local MySQL credentials.
4. Run the application using `./mvnw spring-boot:run` (or via your IDE).

### Starting the Frontend
1. Navigate to the `frontend` directory.
2. Run `npm install` to retrieve dependencies.
3. Run `ng serve` to launch the development server.
4. Access the dashboard at `http://localhost:4200`.
